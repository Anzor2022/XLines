# Проверки комплекта XLines 0.6

ВАЖНО: версия с несколькими серверами (Library.kt, MainActivity.kt, Secrets/Service) в этой среде не
компилировалась и не тестировалась: нет Android SDK и Kotlin-компилятора, Maven заблокирован. Код проверен вычиткой и
балансом скобок. Ниже — результаты предыдущей базы.

Выполнено в этой среде:

- 31 тест Python/Qt Windows-логики: интерфейс, протоколы, файл/URI, лимиты импорта,
  непринятие небезопасных TLS-параметров, scoped removal на временных тестовых папках,
  отказ удалять чужую службу, смена учётных данных при повторной выдаче отозванного слота.
- Окна XLines, «Поделиться» и SSH-мастер реально отрисованы Qt offscreen в Linux.
- Два транспортных профиля тестового клиента дают QR URI размером 2070 ASCII байт
  при лимите 2200. Раздельные: VLESS 456 байт, Hysteria2 1810 байт.
- Kotlin/Compose скомпилированы; 4 JVM-теста читают Python-generated golden .xlines/URI,
  проверяют перенос сертификата Hysteria2 и запрет TLS insecure. lintDebug прошёл.
  Для этой локальной проверки использовался пустой compile-only AAR без native engine.
  Он удалён из источников и исключён из всех ZIP. APK без ядра не распространяется.
- GitHub workflow собирает настоящий libbox из pinned commit до сборки APK.
  Сам полный native build в GitHub в этой сессии не запускался.

Не проверено, не выдаётся за готовое:

- Windows EXE/установщик на реальном PC, нативный libbox на Android,
  полный GitHub workflow, реальный импорт QR с камеры устройства.
- Установка/удаление через SSH на чистом VPS и firewall провайдера.
  Тесты удаления используют временные папки, не настоящий VPS/systemd/UFW.
- Production-аудит, тесты утечек и нагрузка 6 пользователей.
- iOS-клиент не создан; только переносимый формат версии 1.

До проверки не удаляйте рабочую прежнюю версию. В сборках используйте собственные
конфигурации, а не демонстрационные тестовые профили с адресами документации.
