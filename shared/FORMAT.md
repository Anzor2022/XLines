XLines v1: JSON {format:"xlines",version:1,name,connections:[{name,outbound}]}.
URI: xlines://import?data=base64url(zlib(UTF8 JSON)), without padding.
Decoded size limit: 262144 bytes. QR URI limit: 2200 ASCII bytes.
Only literal server IP, VLESS+REALITY allowed (other transports are dropped on import). TLS verification mandatory.
No SSH credentials or server private keys. Files/QR contain client credentials.
iOS client not implemented; this is a portable format specification, not existing iOS support.
